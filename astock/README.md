# A 股短线策略：超跌放量反弹 · 尾盘确认

> 不构成投资建议。没有任何策略能保证赚钱，下面所有数字都是历史回测，未来可能完全不同。

## 一句话

平时空仓。只有当**全市场同一天出现 ≥10 只**「远低于 60 日线、当天放量大涨」的股票时（恐慌出清后的集体反转），
尾盘买入其中涨幅最大的 10 只，持有 3 个交易日后尾盘卖出。

## 规则

| 环节 | 条件 |
|---|---|
| 股票池 | 沪深主板 + 创业板；剔除 ST、上市不足 120 个交易日、成交额 < 1 亿、股价 < 2 元 |
| 个股信号（T 日 14:50） | 收盘价 ≤ MA60 × 0.8；当日涨幅 3%～9.5%（未封涨停，尾盘买得到）；量比（当日量 / 前 5 日均量）≥ 1.5 |
| 开仓开关 | 当日满足个股信号的股票 ≥ 10 只，否则不开仓 |
| 选股 | 按当日涨幅从高到低，最多买 10 只 |
| 仓位 | 账户分 10 份，每只 1 份；仓位满了不再买 |
| 卖出 | 第 3 个交易日尾盘卖出；期间任一收盘较买入价跌超 10% 当天尾盘止损；跌停封死卖不出则顺延 |

所有参数在 `strategy.py` 的 `Params` 里。

## 回测结果（2021-07 ～ 2026-11，含退市股）

成本：佣金万 2.5 双边，印花税 0.1%（2023-08-28 后 0.05%），滑点每边 0.15%。

| 区间 | 交易笔数 | 胜率 | 单笔均值 | 年化 | 最大回撤 | 夏普 | 同期上证 |
|---|---|---|---|---|---|---|---|
| 样本内 2021-07 ～ 2024-06 | 80 | 75% | +4.7% | +12.9% | -3.6% | 1.51 | -17.3% |
| 样本外 2024-07 ～ 2026-11 | 120 | 58% | +2.4% | +12.3% | -12.5% | 0.98 | +22.1% |

参数只用样本内数据选定（`python3 -m astock.run tune`）；网格里 24 组参数在样本外全部为正收益。

压力测试（全区间）：

| 情形 | 年化 | 最大回撤 |
|---|---|---|
| 基准（200 笔，胜率 65%，累计 +88.5%） | +12.6% | -12.5% |
| 尾盘没买到，改次日开盘买 | +14.8% | -12.3% |
| 滑点翻倍到每边 0.3% | +11.4% | -12.8% |
| 只做流通市值 ≥ 30 亿 | +11.7% | -8.6% |
| 持有 5 天 | +6.7% | -17.1% |

对照组——网上流传的「经典尾盘埋伏」（涨 3–5%、放量、收在高位、均线多头、次日卖）：
1610 笔，胜率 30%，单笔 -0.9%，**5 年亏损 99%**。A 股热门股隔夜均值回归，追强在扣费后持续亏钱。

## 必须知道的风险

1. **样本很少。** 5 年只有 20 个开仓日、大约 7 轮行情（2022-04、2024-02、2025-04、2026-07/08 等），统计上远谈不上确定。
2. **大部分时间空仓。** 资金利用率很低，年化 12% 是总资金口径；一年可能完全没有信号（2023 年就没有）。
3. **抄的是恐慌盘。** 2026-07-10 一轮就亏了 7.6%；如果遇到持续数周的系统性下跌，连续触发会连续亏。
4. **回测用收盘价近似 14:50 成交。** 次日开盘买入的压力测试没有变差，但实盘成交仍会有偏差。
5. 历史 ST 状态用「120 日内涨跌幅被限制在 5%」推断，不完全准确；数据来自东方财富公开接口，可能有误差或中断。

## 使用

```bash
pip install -r astock/requirements.txt

python3 -m astock.run download   # 收盘后（15:30 以后）全量更新日线并重建面板，约 15–30 分钟
python3 -m astock.run backtest   # 回测报告：样本内外、逐年、开仓日明细、压力测试、对照组
python3 -m astock.run tune       # 参数网格（只按样本内排序）
python3 -m astock.run screen     # 交易日 14:45–14:50 运行，输出今天的信号和是否开仓
python3 -m astock.research       # 因子分组研究（样本内）
python3 -m astock.check_screen 2024-02-06 2026-11-05   # 核对实盘选股与回测信号一致
```

`screen` 依赖本地缓存的历史日线，需要每天收盘后先跑一次 `download`。

## 文件

- `data.py` — 东方财富行情：股票列表（含已退市）、前复权日线、实时快照
- `strategy.py` — 特征、信号、参数；同时保留经典尾盘埋伏作为对照
- `backtest.py` — 按 A 股规则撮合（T+1、涨停买不进、跌停卖不出）+ 分仓账户模拟
- `run.py` — 命令行入口
- `research.py` — 因子十分位研究
- `check_screen.py` — 实盘路径与回测路径一致性检查
