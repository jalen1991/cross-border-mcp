# A 股短线策略：超跌放量反弹 · 尾盘确认

> 不构成投资建议。没有任何策略能保证赚钱，下面所有数字都是历史回测，未来可能完全不同。

## 一句话

平时空仓。只在**全市场恐慌出清**时出手：前一天收盘有 ≥15% 的股票跌破 60 日线两成以上，且今天有 ≥5 只
「远低于 60 日线、当天放量大涨」的股票，就在尾盘把它们买进（最多 20 只，每只 1/20 仓位），持有 3 个交易日后尾盘卖出。

## 规则

| 环节 | 条件 |
|---|---|
| 股票池 | 沪深主板 + 创业板；剔除 ST、上市不足 120 个交易日、成交额 < 1 亿、股价 < 2 元 |
| 个股信号（T 日 14:50） | 现价 ≤ MA60 × 0.8；当日涨幅 3%～9.5%（未封涨停，尾盘买得到）；量比（当日量 / 前 5 日均量）≥ 1.5 |
| 开关 1：恐慌广度 | T-1 收盘，成交额 ≥ 1 亿的非 ST 股里，现价 ≤ MA60 × 0.8 的占比 ≥ 15% |
| 开关 2：信号数量 | T 日满足个股信号的股票 ≥ 5 只 |
| 仓位 | 账户分 20 份，每只 1 份；没有空仓位就不买 |
| 卖出 | 第 3 个交易日尾盘卖出；期间任一收盘较买入价跌超 10% 当天尾盘止损；跌停封死卖不出则顺延 |

所有参数在 `strategy.py` 的 `Params` 里。

### 为什么是这些规则

- **追强会亏。** 网上流传的「经典尾盘埋伏」（涨 3–5%、放量、收在高位、均线多头、次日卖）回测 1610 笔，
  胜率 30%，5 年亏 99%。因子研究显示：换手率、近期涨幅、偏离均线最高的那 10% 股票，后面 1～5 天都系统性跑输。
- **恐慌后的放量反弹才有优势**，而且只在全市场恐慌时成立；零星个股的超跌反弹扣费后没有优势。
- **恐慌广度比信号数量更能区分好坏行情**（与该轮收益的相关系数 0.51 对 0.36）。它是比例，不受股票总数逐年变化影响。
- **在候选股里怎么排序不重要**：按涨幅挑前 10 只（+3.44%）不比随机挑（+3.77%）或全买（+3.78%）好，
  所以分成 20 份尽量多买、分散，而不是挑。

## 回测结果（2021-07 ～ 2026-11，含退市股）

成本：佣金万 2.5 双边，印花税 0.1%（2023-08-28 后 0.05%），滑点每边 0.15%。

| 区间 | 交易笔数 | 胜率 | 单笔均值 | 年化 | 最大回撤 | 夏普 | 同期上证 |
|---|---|---|---|---|---|---|---|
| 样本内 2021-07 ～ 2024-06 | 127 | 81% | +6.2% | +13.6% | -1.1% | 1.77 | -17.3% |
| 样本外 2024-07 ～ 2026-11 | 164 | 62% | +3.0% | +10.5% | -7.5% | 1.06 | +22.1% |
| 全区间 | 291 | 70% | +4.4% | +12.2% | -7.5% | 1.39 | |

**更诚实的估计——滚动向前检验**（`python3 -m astock.run walkforward`）：每年只用此前的数据从参数网格里选参数，
再拿去交易当年。2023 ～ 2026 拼接：194 笔，胜率 57%，**年化 +7.1%，最大回撤 -14.4%**，夏普 0.64；
同期上证累计 +17.4%、最大回撤 -20.4%。这比上表低，差距就是「事后挑参数」带来的乐观偏差，实盘预期应以它为准。
恐慌广度开关在 4 年里有 3 年被独立选中（都是 15%）。

### 两档：稳健（默认）与积极

`screen` / `backtest` 等命令都接受 `--profile steady|aggressive`。两档只差恐慌广度开关：积极档去掉开关，
只要当天信号 ≥ 5 只就买。

| 档位 | 区间 | 笔数 | 胜率 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|---|---|---|
| 稳健 `steady`（广度 ≥ 15%） | 样本内 | 127 | 81% | +13.6% | -1.1% | 1.77 |
| | 样本外 | 164 | 62% | +10.5% | -7.5% | 1.06 |
| 积极 `aggressive`（无开关） | 样本内 | 308 | 58% | +11.1% | -8.3% | 1.22 |
| | 样本外 | 287 | 55% | +13.8% | -10.0% | 1.20 |

积极档在样本外（含 2024 年 9 月后的上涨）赚得更多，但样本内明显更差、回撤更深；滚动检验 4 年里有 3 年选中开关，
所以默认用稳健档。积极档适合愿意多交易、能接受约 -10% 回撤的人。

压力测试（全区间）：

| 情形 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|
| 基准 | +12.2% | -7.5% | 1.39 |
| 尾盘没买到，改次日开盘买 | +13.4% | -7.3% | 1.49 |
| 滑点翻倍到每边 0.3% | +11.3% | -7.8% | 1.31 |
| 去掉恐慌广度开关 | +12.3% | -10.0% | 1.20 |
| 恐慌广度门槛 10% / 20% | +10.8% / +11.5% | -10.0% / -4.3% | 1.14 / 1.49 |
| 候选股里伪随机挑选 | +13.1% | -7.2% | 1.44 |
| 持有 2 天 / 5 天 | +11.1% / +9.4% | -9.7% / -8.8% | 1.16 / 1.01 |
| 只做流通市值 ≥ 30 亿 | +10.1% | -6.6% | 1.23 |

### 14:50 实盘成交验证

东方财富 5 分钟线只保留最近约 7 周，覆盖 2026-10-28、11-02、11-04 三个开仓日：

- 这些日子候选股从 14:50 到收盘平均又涨了约 0.3%，**14:50 买入比回测假设的收盘价更便宜**，回测偏保守。
- 14:50 时全天成交量平均只完成 95.7%，直接算量比会让大部分「收盘时才达标」的股票卡在 1.45～1.49。
  `screen` 因此按已交易时间把成交量折算成全天估计（14:50 约 ÷0.958）。
- 折算后用 14:50 的 5 分钟线逐只重放：收盘时达标的 77 只里 72 只（93.5%）在 14:50 同样达标，
  另有 9 只 14:50 达标、收盘没达标。14:50 实际会买的 81 只，3 日毛收益 +0.35%，回测口径那 77 只是 +0.08%。
  只有 3 个开仓日，样本很小，只能说明 14:50 执行没有明显偏离回测，不能当作额外收益。
- 资金较小时单仓买不起一手的股票（`shares=0`）直接跳过，不要挪用其他仓位。

## 必须知道的风险

1. **样本很少。** 5 年里约 30 个开仓日、6～7 轮行情（2022-04、2024-02、2025-04、2026-07/08、2026-11），统计上远谈不上确定。
2. **大部分时间空仓。** 年化是总资金口径；可能整年没有信号（2023 年就没有）。
3. **抄的是恐慌盘。** 2026-07-10 一轮亏 7.4%，2026-10-28 一轮亏 9.3%；持续数周的系统性下跌会连续触发、连续亏。
4. 回测用收盘价近似 14:50 成交、只在收盘检查止损；历史 ST 状态用「120 日内涨跌幅被限制在 5%」推断；
   数据来自东方财富公开接口，可能有误差或中断。

## 使用

```bash
pip install -r astock/requirements.txt

python3 -m astock.run download      # 每个交易日收盘后（15:30 以后）：全量更新日线、重建面板和恐慌广度，约 15–30 分钟
python3 -m astock.run screen --capital 1000000            # 交易日 14:45–14:50：今天卖什么、买什么、各多少股
python3 -m astock.run screen --capital 1000000 --record   # 按提示成交后再跑一次，把买卖记入持仓文件

python3 -m astock.run backtest      # 回测报告：样本内外、逐年、开仓日明细、压力测试、对照组
python3 -m astock.run walkforward   # 滚动向前检验
python3 -m astock.run tune          # 参数网格（只按样本内排序）及各参数维度的中位数
python3 -m astock.research          # 因子分组研究（样本内）
python3 -m astock.check_screen 2024-02-06 2026-11-02   # 核对实盘选股与回测信号一致
```

持仓记录在 `astock/data/positions.csv`（不进 git）。`screen` 会先列出持仓：满 3 个交易日或收盘前亏超 10% 的提示卖出，
卖出腾出的仓位当天可以再买。

## 文件

- `data.py` — 东方财富行情：股票列表（含已退市）、前复权日线、实时快照
- `strategy.py` — 特征、信号、参数；同时保留经典尾盘埋伏作为对照
- `backtest.py` — 按 A 股规则撮合（T+1、涨停买不进、跌停卖不出）、分仓账户模拟、恐慌广度
- `run.py` — 命令行入口：下载、回测、调参、滚动检验、实盘选股与持仓记录
- `research.py` — 因子十分位研究
- `check_screen.py` — 实盘路径与回测路径一致性检查
